# GAP: Narrowing Posture Transition

> Status: candidate / proposed doctrine. Filed 2026-05-10 with a
> witness pair and a live in-session counterexample.
> **No implementation.** No `work_phase` field, no `narrowing_role`
> field, no static phase taxonomy. The diagnostic question is the
> deliverable. A record is not authorization to build.

## Why this is named now

A witness pair, plus a live counterexample that surfaced during
the filing pass.

**Witness 1 — cross-project, operator-side.** A research-corpus
note titled *"third-order cybernetics"* served as a useful
exploratory handle for several months while the actual axis
("signals arriving already-laundered into authority") came into
focus. Once the admissibility axis stabilized, the ordinal name
became overclaim — the move that *finished* the framing was
retirement to *"admissibility-cybernetics"*, narrower-but-
stronger. The earlier name was scaffolding, not failure. Same
narrowing move that finished the work would have *aborted* the
same work five months earlier.

**Witness 2 — cross-session, recurring.** Multiple sessions have
applied YAGNI-shaped pruning to category-requirement work —
CPU/memory/disk monitoring on a monitor, egress gating on a
hosted-LLM backend, receipts on an authority layer — requiring
operator override to re-establish that the work is table stakes,
not speculative. The litmus already in global CLAUDE.md catches
this at the category boundary. It does not catch the search-
epistemology variant.

**Witness 3 — in-session, live counterexample.** While drafting
this very GAP through an out-of-band review pass, the reviewer
proposed Night Shift carry the operational artifact as
`work_phase: exploratory_probe | ratification_pass | …` — a
static enum field. That proposal landed in the same message that
endorsed *"transitions, not nouns"* (the candidate sharpening in
`GAP-lesson-distillation-boundary.md`). The enum is exactly the
move that rule refuses, and it surfaced as a "feels operational"
reflex *while the rule was named*. The live counterexample is
load-bearing for this GAP's filing posture: the failure mode is
reachable by the same actor, in the same conversation, minutes
after the rule is invoked. The doctrine arrived wearing the face
of the actor it warns against.

## Keeper lines

Three load-bearing lines.

> **The same narrowing move can finish one workstream and abort another.**

(Anchor — keeper-grade compression.)

> **Narrow after contact. Do not narrow before contact.**

(Operational form. Where the rule is reached for during work.)

> **Exploration needs surplus meaning. Ratification needs minimum sufficient meaning.**

(Why form. Where the rule is justified.)

## Core diagnostic

> **Is this narrowing finishing something already found, or aborting the search before contact?**

This is the deliverable. The diagnostic surfaces *into review and
reconciliation*; it does not become a label that decides on the
work's behalf. The form is a question on purpose: compression to a
single-word answer recreates the failure mode the diagnostic
exists to detect.

## Named transitions

The diagnostic is operationally relevant where narrowing-posture
*flips* across a transition. Five named transitions; recognition
handles, not a finite partition of work states. Each is a trigger
condition for asking the diagnostic question.

### pre-contact → post-contact

Surplus meaning stops being scaffolding and starts becoming
overclaim. Wider names, provisional metaphors, and weird handles
are load-bearing during search; once the shape lands, the same
breadth becomes excess structure. The flip is not visible from
either side alone — only across the transition.

### exploration → ratification

Broad handles become public-framing liabilities. Names that helped
*locate* a thing now must stop cosplaying as larger claims. The
narrowing move that finishes (smallest accurate claim) is the
same narrowing move that would have aborted the search three
weeks earlier. Witness 1 lives here.

### apparent-scope-creep → category-requirement

YAGNI stops applying because the work is table stakes for the
category. CPU/memory/disk for a monitor, egress gating for hosted
LLM backends, receipts for an authority layer. The narrowing
posture flips not because the work changed but because the
category surfaces. The litmus in global CLAUDE.md catches this
transition in isolation; it is named here for completeness with
the others. Witness 2 lives here.

### ratification → execution

Accepted scope should be preserved, not endlessly reopened. Once
the framing has landed and the work has begun, narrowing posture
flips from *"find smallest accurate claim"* to *"preserve the
claim already accepted."* Reopening for further narrowing during
execution is the *agenda-reconciler trap* by another name —
turning the work into reflection on the work.

### execution → maintenance

Narrowing should avoid re-litigating doctrine unless new failure
evidence appears. Maintenance posture defaults to *preserve unless
forced*. The transition arrives quietly; failing to notice it
produces steady erosion of accepted scope by ambient pruning
pressure.

## Connection to existing doctrine

This GAP sits across, not on top of, several existing pieces.

- **Kind-of-work-changed (CLAUDE.md "What This Is").** That
  doctrine is the *transition detector* — Night Shift notices
  when the kind of work has changed. This GAP is the *posture
  rule* — what changes about narrowing across the transition.
  Sibling, not duplicate.

- **Transitions, not nouns (`GAP-lesson-distillation-boundary.md`,
  candidate sharpening).** The discipline this GAP itself obeys:
  name the transition where posture flips, do not mint a noun for
  the phase. Witness 3 makes this connection load-bearing rather
  than ceremonial.

- **Agenda-reconciler trap (memory feedback).** *"Do not
  file/build agenda-level reconciliation without a failing case;
  over-productizing the coping strategy is the named failure
  mode."* The `work_phase` enum is precisely the over-productize-
  the-coping-strategy shape this trap names. This GAP files the
  *recognition*; it explicitly does not file the *machinery*.

- **YAGNI litmus (global CLAUDE.md).** *"If 'out of scope' blocks
  table-stakes work for the category, the YAGNI reflex may be
  misfiring."* That litmus catches the apparent-scope-creep →
  category-requirement transition in isolation. This GAP names it
  alongside the others to surface the broader pattern.

- **`feedback_narrow_after_contact` (NQ memory, peer filing).** NQ
  filed a feedback memory covering the diagnostic from a different
  angle. NQ's framing is *search-epistemology*; the existing
  `feedback_preemptive_naming` covers *surface-economics*
  (retrofit cost on architectural seams). Cousins, not aliases.
  The Night Shift filing differs in scope: NS surfaces the
  diagnostic into cross-session reconciliation and review; NQ
  remembers it as a per-session reflex.

- **`GAP-autonomous-execution-boundary.md`.** Structural sibling.
  That GAP's master keeper — *trigger conditions authorize a
  question, they do not authorize an actor* — has the same shape
  as this GAP's structural rule: *phase observations authorize a
  question, they do not authorize a label that decides on the
  observation's behalf.* Both refuse the move from a real signal
  to a static field that decides without review.

## What this does not authorize

Per Witness 3 and the *transitions, not nouns* discipline:

- **No implementation.** No `work_phase` field on schedule
  entries, bundles, packets, or run ledger rows. No
  `narrowing_role` field. No phase classifier, no auto-detection
  routine, no transition state machine.
- **No phase enum.** Not `exploratory_probe | ratification_pass |
  core_requirement | execution_work | maintenance_work`, not any
  variant. The keeper is *the same narrowing move can finish one
  workstream and abort another* — compression to an enum value is
  the laundering shape this GAP exists to refuse.
- **No taxonomy as ratified plan.** The five named transitions
  above are recognition handles, not a closed partition. Adding
  more transitions is a separate move with its own evidence; the
  five are not exhaustive.
- **No diagnostic-as-decision.** The diagnostic question surfaces
  for review. It does not produce a verdict the system acts on.
  Treating *"this is exploration"* as a decision the work then
  inherits is the same move as compressing a new case into an old
  motif without showing differences (per
  `GAP-lesson-distillation-boundary.md`).
- **No new authority.** This GAP changes nothing about Governor's
  ceiling, Night Shift's posture, NQ's testimony, or Continuity's
  standing. It is coordination posture, not authority.

A record is not authorization to build.

## Trigger conditions for ratification

Promote to non-candidate when one of these fires:

1. Night Shift surfaces the diagnostic question into a real
   reconciliation pass and the surface shape needs specification.
2. Two or more independent operator-side witnesses of the
   diagnostic catching a misfire that existing CLAUDE.md doctrine
   missed.
3. A second sibling GAP finds itself reaching for this rule by
   name and benefits from a stable reference shape.
4. The five named transitions accrue enough evidence that a
   recognition guide (which transition this is, what to look for)
   becomes a real artifact.

Until one of those fires, this GAP carries only the keeper lines,
the diagnostic question, the named transitions, the doctrinal
connections, and the explicit non-authorization. The diagnostic
is the deliverable; the field is not.
