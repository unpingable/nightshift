# Historical Watchbill test specimens

These files preserve pre-cutover regression evidence for the retired
Watchbill/NQ-import/packet runtime. Cargo does not discover integration-test
sources below this directory, and canonical Nightshift does not compile the
modules they reference.

They are noncanonical reference material, not a selectable test or runtime
profile. Current recurrence, posture, currentness, attention, restart, AG, and
nonauthority invariants live in the canonical module tests and the active
integration sentinels one directory above.
